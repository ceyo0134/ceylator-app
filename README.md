# Ceylator

Android üzerinde Windows uygulamalarını çalıştırmak için Wine/Box64 tabanlı bir uygulama.

- Siyah varsayılan masaüstü arka planı
- Mor temalı, koyu arayüz
- Özelleştirilmiş isim ve ikon
